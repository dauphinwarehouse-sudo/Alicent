# Формат проекта v2

Основа и ограничения размера документов сохранены из [v1](project-format-v1.md). Единственный источник истины — SQLite в папке `<uuid>.alicent`.

## Новые данные

- `project.revision INTEGER NOT NULL`: глобальная ревизия, увеличивается при вставке/обновлении документа.
- `checkpoints(id, name, created_at)`: именованные контрольные точки.
- `checkpoint_documents(checkpoint_id, document_id, revision)`: ссылки на `versions`, без копирования всего текста.
- `PRAGMA user_version=2` и `project.schema_version=2`.

Возврат точки восстанавливает тексты существующих сцен и заметок. Папки, названия, порядок и новые документы не откатываются. Для возврата всего проекта используется резервная копия в **новой папке**. Многодокументный возврат создаёт автоматическую контрольную точку предыдущих текстов, пригодную для отмены. Повторный идентичный `command_id` возвращает сохранённую квитанцию.

## Резервные копии

В меню **Сохранность** доступно создание проверенного `.alicent-backup` в выбранном каталоге. Файл содержит базу, историю и точки; не требует WAL-sidecars. Не зашифрован. Восстановление доступно и со стартового экрана. Приложение сначала сохраняет текущий черновик, затем открывает восстановленную копию отдельной папкой. Отмена выбора ничего не переключает.

При открытии v1 миграция создаёт самостоятельный backup прежней версии в подпапке `backups` до изменения схемы. Старое приложение откажется открыть v2. Чтобы использовать v1-backup со старым приложением, создайте **новую пустую папку** `<любое-имя>.alicent` и скопируйте туда исходную v1-копию под именем `project.sqlite3`. Не заменяйте файл работающего проекта. Новое приложение при открытии этой папки автоматически выполнит v1→v2 с новым backup.

Подробная семантика и ограничения: [ADR 0006](adr/0006-recovery-and-checkpoints.md).
