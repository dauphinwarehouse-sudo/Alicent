# ADR 0003 — CodeMirror 6 для Markdown-прототипа

Статус: временно принято для Markdown-среза; rich text остаётся требованием.

Контекст: ТЗ рекомендует ProseMirror/TipTap, одновременно требует виртуализации длинных документов. Проверять всё сразу одним editor model рискованно.

Решение: первый исполнимый срез использует CodeMirror 6: готовая viewport virtualization, Markdown language support, локальный undo/redo и доступный текстовый интерфейс. Этот выбор НЕ означает отказа от rich text. ProseMirror/TipTap нужно сравнить на документе 200k слов до окончательного решения; измеримых результатов такого сравнения пока нет.

Альтернатива textarea отклонена из-за отсутствия viewport virtualization и редакторских команд. TipTap не отвергается — отложен до прототипа rich text и канонической схемы блоков.

Последствия: формат проекта сейчас Markdown v1, форматированного режима нет. При переходе к блочной схеме требуется lossless migration и fixtures; нельзя сохранять HTML поверх пользовательского Markdown без преобразования/версии.
