# ADR 0005 — Интерфейс с визуальным референсом Ficbook

Статус: принято по запросу владельца. Изменяется представление, не формат данных и не command layer.

## Референс и наблюдения

Просмотрены публичные страницы https://ficbook.net/ и https://ficbook.net/faq в браузере: главная, карточки работ и текстовый раздел FAQ. Наблюдались тёмно-коричневая внешняя рамка (computed body background `#413023`), кремовые поверхности, охристые ссылки/акценты, Verdana в интерфейсе, горизонтальная навигация и компактные метаданные. Реклама, тексты произведений и изображения не нужны писательскому редактору.

## Решение для Alicent

- Коричневое обрамление, светлая «бумажная» рабочая область, охристая иерархия заголовков и выбранных строк.
- Verdana для навигации/метаданных, Georgia для длинного текста и стартового заголовка. Системные шрифты, без сетевой загрузки.
- Двухуровневая шапка и настоящие ссылки к рукописи, редактору и истории. Переход из focus mode возвращает панели, но не меняет выбранный документ.
- Компактные карточки версий, светлая полоса сохранения и книжное оформление модальных окон.
- Собственная тёмная тема с тёплыми тонами по `prefers-color-scheme`; контраст текста и Markdown-маркеров проверяется автоматически.
- Название Alicent и исходная A-монограмма сохранены; иконка перекрашена в ту же палитру.
- При ширине 390 px дерево, редактор и история идут последовательно, а не скрываются.

Фирменный знак Ficbook, его CSS/JS, обложки и тексты не копируются. Подключения к Ficbook, импорта, публикации произведений и авторизации на сайте нет. Это визуальный референс, не интеграция или аффилиация.

## Проверки и границы

`npm run check`: форматирование, ESLint, TypeScript, 12 frontend/component tests, 3 CI-report tests и production Vite build. `npm run test:ui`: 9 browser scenarios — существующие операции плюс light/dark, контраст, focus/navigation, 390 px и сохранность черновика при тестовой ошибке. Тестовый port и fault injection остаются только в `apps/desktop/tests`.

Визуально проверяются стартовая страница, workspace, focus, light/dark dialogs, diff, error и mobile states. Прототип по-прежнему не содержит AI runtime и rich-text режима. Native/Windows regression выполняется отдельным CI; browser fixture не выдаётся за тест установленного приложения.
