# Локальный формат проекта v1

```
<random-uuid>.alicent/
  project.sqlite3
  project.sqlite3-wal   # может существовать при открытом соединении
  project.sqlite3-shm   # может существовать при открытом соединении
```

Папка не зависит от названия рукописи. Имена документов никогда не становятся путями. Root выдаётся нативным диалогом и хранится только в адаптере, не в доменной модели. Внутри одного проекта ID не используются для обращения к другому проекту.

## Схема

Истина — `crates/project-repository/src/schema.sql`.

- `project`: UUID, заголовок, версия схемы, время создания UTC.
- `documents`: UUID, parent UUID, title, kind (`folder`, `scene`, `note`), содержимое Markdown UTF-8, revision, updated_at. Folder не содержит текст.
- `versions`: полные версии `(document_id, revision)`, текст, actor и timestamp. Версия 0 создаётся вместе с документом.
- `operations`: UUID операции, document ID, версия протокола 1, actor, вид (`create`, `save`, `restore:N`), SHA-256 before/after, revision, timestamp.
- `receipts`: command UUID, SHA-256 запроса и результат для безопасного повтора save/restore.
- `document_fts`: внешний FTS5 индекс (`unicode61`) с синхронными INSERT/UPDATE-триггерами.

Формат `PRAGMA user_version = 1` дополнительно проверяется по `project.schema_version`. Дата — UTC ISO 8601. SHA-256 здесь связывает журнал с текстом, **не является криптографической подписью или защитой от локального редактирования базы**.

## Транзакционные гарантии

Режим WAL, foreign keys, `synchronous=FULL`, busy timeout 3 секунды. Создание документа, сохранение и восстановление атомарны вместе с версиями/журналом/индексом. Ошибка после начала транзакции откатывает её при drop. Подтверждение возвращается только после commit. `trusted_schema=OFF` ограничивает выполнение недоверенной схемы.

Восстановление создаёт новую ревизию; старые строки versions не перезаписываются. `expected_revision` предотвращает lost update между процессами. Replayed save с теми же параметрами возвращает исходный receipt; это не обязательно самая новая ревизия — клиент должен перечитать документ, если после повтора были другие записи.

## Версии и миграции

В прототипе **нет миграций**. Неизвестный user_version отвергается, не понижается и не преобразуется. До первой миграции обязательны backup через SQLite Backup API, миграционный тест и crash injection. Нельзя трактовать отказ открытия старого формата как миграционную поддержку.

## Перенос и ограничения

Закрыть все окна Alicent и скопировать всю папку. Не переносить открытую базу отдельным файлом. Не использовать network share/cloud-synced folder: WAL требует корректных локальных блокировок. Архивный перенос, шифрование и live backup ещё не реализованы.

8 МиБ на документ — явная граница первого среза. Файловые вложения отсутствуют. Unicode сохраняется без перекодировки; счётчик слов интерфейса приблизительный (по whitespace), не лингвистический токенизатор. Порядок списка — папки сначала, затем title и UUID, пользовательского order key пока нет.
