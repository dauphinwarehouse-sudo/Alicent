# Формат проекта v5: политика контекста ИИ

## Цель

Версия 5 хранит пользовательскую политику ИИ рядом с документом. Автор может закрепить до восьми сцен или заметок как постоянный контекст либо полностью исключить документ из запросов к модели.

## Схема и инварианты

В `documents` добавлены два обязательных флага:

- `ai_context_excluded INTEGER NOT NULL DEFAULT 0`;
- `ai_context_pinned INTEGER NOT NULL DEFAULT 0`.

Оба значения ограничены `0/1`. Триггеры запрещают одновременно исключить и закрепить одну строку. Строгая проверка проекта дополнительно проверяет значения, взаимное исключение и глобальный лимит восьми активных закреплённых документов.

Индекс `documents_ai_context(ai_context_pinned, ai_context_excluded, updated_at, id)` обслуживает bounded-запрос постоянного контекста. Папки нельзя менять через policy command и они не попадают в результат.

## Команда и поведение

`set_document_ai_context` принимает `command_id`, `document_id`, `expected_revision`, `excluded` и `pinned`.

Изменение политики:

1. проверяет revision и лимит закреплений;
2. обновляет флаги и revision;
3. добавляет metadata-version с неизменным текстом;
4. записывает `operations(kind='ai_context')` и payload-bound receipt в той же транзакции.

Точный повтор команды возвращает прежний результат. Повтор `command_id` с другим payload даёт `CommandMismatch`, а устаревшая revision — `Conflict`. No-op также получает receipt, но не создаёт новую revision.

Архивирование атомарно снимает закрепление со всего архивируемого поддерева. После восстановления документы остаются незакреплёнными. Исключение сохраняется. Дубликат наследует исключение исходника, но не закрепление.

## Использование в редакторе

При открытии проекта UI отдельно загружает не более восьми активных закреплённых сцен и заметок. Они автоматически отмечаются в списке контекста, даже если находятся вне текущей папки. Пользователь может снять выбор для конкретного запроса.

Исключённые документы:

- не показываются среди reference-кандидатов;
- повторно отклоняются после чтения непосредственно перед генерацией;
- не могут быть текущей целью запроса, пока автор явно не разрешит ИИ.

Существующие границы сохраняются: максимум восемь references, 512 КиБ в renderer и 2 МиБ на native provider boundary.

## Миграция v4→v5

Перед изменением создаётся самостоятельный validated backup:

`backups/pre-migration-v4-<uuid>.alicent-backup`

После успешной публикации backup одна транзакция добавляет столбцы, индекс и триггеры, затем обновляет `project.schema_version` и `PRAGMA user_version` до 5. Старые документы получают оба флага `false`.
