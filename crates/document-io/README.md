# alicent-document-io

Изолированные примитивы импорта/экспорта документов. Crate не зависит от UI,
редактора, схемы проекта, repository, provider или tool runtime.

## Реализовано

- потоковый импорт и экспорт UTF-8 Markdown/TXT через `Read` → `Write`;
- побайтовый Unicode round-trip без нормализации BOM, переводов строк или
  Unicode normalization form;
- отдельные лимиты входа, выхода и буфера (буфер жёстко ограничен 1 МиБ);
- reusable archive budget для будущих ZIP-контейнеров DOCX/EPUB:
  лимиты числа записей, размера записи, суммарной распаковки, compression ratio,
  длины/глубины пути и проверка фактических распакованных байтов;
- запрет абсолютных, traversal, Windows drive/ADS, backslash и неоднозначных
  archive paths;
- синтетические Unicode и adversarial fixtures/tests.

## Не реализовано

DOCX/EPUB adapters ещё не включены: этот PR готовит обязательный безопасный
слой, но не заявляет поддержку контейнеров. PDF и Fountain не реализованы.

Семантическое преобразование Markdown ↔ plain text намеренно находится вне
byte-preserving API: потребитель должен выбрать правила преобразования явно.
При ошибке в конце потока валидный префикс уже может находиться в `Write`;
для атомарной публикации следует писать во временный файл и переименовывать его
только после успешного результата.
