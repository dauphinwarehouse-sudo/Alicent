# Alicent

Локальная среда для писателей. Windows 10/11 x64, русский интерфейс, пользователь владеет данными.

**Статус: ранний прототип локального ядра, не готовый MVP.** Реализованы локальный редактор и восстановление данных; агентные функции описаны контрактами, но ещё не работают. Результаты и границы проверок: [docs/verification.md](docs/verification.md).

## Уже реализовано

- Создание нового проекта через системный выбор каталога, повторное открытие.
- Папки с вложенностью, сцены и заметки; постраничное чтение списка документов.
- Markdown-редактор CodeMirror с виртуализацией viewport, undo/redo, переносом строк и режимом фокуса.
- Последовательное автосохранение через 650 мс после ввода; Ctrl/Cmd+S.
- SQLite WAL, атомарная транзакция текста + версии + журнала + FTS.
- Оптимистическая проверка ревизии: конфликт не перезаписывает текст, несохранённый черновик остаётся в окне.
- Полнотекстовый поиск, просмотр истории, текстовый diff и восстановление отдельной версии как новой правки.
- Резервные копии через SQLite Backup API и восстановление в новую папку.
- Именованные контрольные точки текстов, подтверждаемый возврат всей рукописи и автоматическая точка отмены.
- Миграция v1→v2 с обязательной резервной копией прежней схемы.
- Светлая/тёмная тема по настройкам системы. Произведения и запросы не передаются в сеть.

## Оформление

UI использует Ficbook как визуальный референс: коричневая рамка, кремовая рабочая область, охристые акценты и компактная навигация. Сохранены название Alicent, собственный код и локальная работа; ассеты сайта не загружаются. Светлая/тёмная темы следуют системным настройкам. Решение и проверки: [ADR 0005](docs/adr/0005-ficbook-inspired-ui.md).

## AI-инфраструктура

Добавлен нативный offline-модуль `crates/provider-wire`: тела запросов трёх протоколов, SSE framing, сборка аргументов инструментов и ограниченная retry-policy. Это **ещё не подключение моделей**: HTTP, хранилище ключей и выполнение инструментов не включены. Границы: [ADR 0007](docs/adr/0007-native-provider-wire-foundation.md).

## Быстрый старт на Windows

Требуется Node.js 22+, Rust **1.94.0**, Microsoft C++ Build Tools (Desktop development with C++), Windows SDK и WebView2 Runtime. На Windows 10 без WebView2 его нужно установить. Рекомендуется локальный диск NTFS, **не сетевой или синхронизируемый облаком каталог**.

```powershell
npm ci
npm run desktop
```

`npm ci` также генерирует локальную иконку приложения из исходного скрипта. Tauri запускает Vite автоматически. При создании выберите родительский каталог: внутри появится новая папка `<uuid>.alicent`. Для открытия выберите именно эту папку, а не `project.sqlite3`.

```powershell
# Проверки
npm run check
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings

# Локальная Windows-сборка (не подписана)
npm run tauri -w @alicent/desktop -- build -- --locked
```

Установщик после успешной сборки: `target/release/bundle/nsis/`. Шаблон `docs/ci/windows-prototype.yml` предусматривает такую же сборку и сохранение installer как artifact, без публикации релиза. **Workflow добавлен** в `.github/workflows/ci.yml` после обновления разрешений подключения. Результат конкретного коммита фиксируется статусом `alicent/ci`; успешная сборка не заменяет native E2E установленного приложения. [Статус CI](docs/ci/README.md). Сертификат подписи и updater пока не настроены.

## Предпросмотр в браузере

```sh
npm ci
npm run dev
```

Откройте `http://127.0.0.1:1420`. Браузер показывает стартовый экран; доступ к проектам **намеренно отключён**, файлового сохранения и поддельного backend нет. В `apps/desktop/tests/fixture.*` находится отдельный тестовый IPC-double для UI-тестов; он не входит в production-сборку.

## Проверки интерфейса

```sh
npx playwright install chromium
npm run test:ui
```

Для системного Chromium на Linux: `CHROMIUM_PATH=/usr/bin/chromium npm run test:ui`. Это browser smoke, **не native Windows E2E**. Ядро также тестируется на аварийный выход отдельного процесса во время транзакции.

## Безопасность данных

Сохранённые транзакции восстанавливаются SQLite после аварии. **Последние символы до автосохранения могут быть потеряны** при отключении питания или убийстве приложения. При обычном закрытии несохранённый текст сначала сохраняется; ошибка оставляет окно открытым. Не закрывайте окно принудительно при ошибке сохранения. При конфликте скопируйте черновик и повторно откройте проект; автоматического слияния пока нет.

Для переноса закройте приложение и копируйте **всю папку проекта**. Копировать только `.sqlite3` у открытого проекта нельзя: подтверждённые данные могут находиться в WAL. Для открытого проекта используйте **Сохранность → Создать резервную копию**. Рекомендуется другой физический носитель. **Открыть из резервной копии** создаёт новую папку, не перезаписывая исходный проект. Подробности: [формат v2](docs/project-format-v2.md).

## Что ещё не реализовано

ИИ endpoints, хранение ключей, streaming, автономные агенты, tool runtime, массовые патчи, карточки сущностей, семантический индекс, rich text, импорт/экспорт, миграции иных форматов помимо v1→v2, автообновление и подписанный installer. Нет drag-and-drop, нескольких вкладок и split view. Ограничение документа — 8 МиБ; хранение полных версий увеличивает объём базы. Целевые показатели 5 млн слов/50 мс **ещё не подтверждены**.
